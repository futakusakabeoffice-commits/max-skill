# 議事録メーカー（練習用・単体）

AIボイスレコーダーの文字起こしを貼るだけで、決まった型の議事録に自動で当てはめるページです。
起業司令室とは別の単体ツールです。必要になったら起業司令室に組み込みます。

- 公開ページ（非公開・本人のみ）: https://claude.ai/artifact/64fRGACYevuJ4Zr9txaZd6
- ソース: `minutes/index.html`
- 保存先: アーティファクトのデータベース（collection: `minutes`）。

## 使い方
1. **作る** → STEP 1 に文字起こしを貼る（または .txt / .srt / .vtt / .md を読み込む）
2. 「AIでテンプレに当てはめる」を押す → STEP 2 のテンプレに自動で入る（手で直せる）
3. 「保存する」「テキストでコピー」（メール・LINE・Slack にそのまま貼れる）
4. 「AIで要約する」→ 3〜5行の要約
5. 送る相手（参加者へ共有／欠席者・上司へ報告／お客さま・社外へお礼と確認）と差出人を選び「AIでメール文を作る」→ 件名と本文をコピー（議事録の全文を最後に付けるかを選べる）

要約とメールは議事録と一緒に保存されます。

AIを使わず、テンプレに手で書き込むこともできます。

## テンプレート（手書き用）
```
【議事録】（会議名）

日時：
場所：
出席者：
欠席者：
記録者：

■ 目的

■ 議題と内容
1. （議題）【決定／保留／継続審議】
　・要点
　→ 結論：

■ 決定事項
・

■ ToDo（担当／期限）
・やること（担当：／期限：）

■ 保留・検討事項
・

■ 次回予定

■ 備考

以上
```

## AIボイスレコーダーとの連携
- **A. レコーダー側でこの型にする**：アプリの「テンプレート」「カスタム要約」などに、ページの「レコーダーと連携」にある指示文を登録する。
- **B. このページで当てはめる**：文字起こしを書き出して STEP 1 に貼る。どの機種でも同じ型にそろう。
