# お問い合わせ自動返信（AI下書き方式）

Googleフォームで受けたお問い合わせに、AI（Claude）が返信文を書いて **Gmailの下書き** に保存します。
送るのは自分で確認してから。誤送信の心配がありません。

## 仕組み
```
お客様がフォーム送信
  ├─ ① お客様へ「受付確認メール」を自動送信（毎回同じ定型文）
  ├─ ② Claude が内容を読んで返信文を作成 → Gmailの下書きに保存
  ├─ ③ あなたに「【要確認】お問い合わせ」通知（分類・急ぎ度・要約・確認してほしい点）
  └─ ④ スプレッドシート「お問い合わせ記録」の「対応ログ」に記録
あなた: Gmailの下書きを開いて、確認・修正して送信
```
- 金額・納期は `CONFIG.businessInfo` に書いたことだけを使い、書いていないことは「お見積もりします」と返します。
- AIが使えないとき（APIキーの誤り、通信エラーなど）は、空欄つきのひな形が下書きに入ります。お問い合わせを取りこぼすことはありません。
- 営業メールやスパムは「spam」に分類し、丁寧なお断り文を下書きにします。

## 設定手順（15分ほど）
1. **Claude APIキーを取る**: https://platform.claude.com でキーを作成（API利用料が別にかかります。1件あたりおよそ数円です）
2. **Apps Script を作る**: https://script.google.com →「新しいプロジェクト」→ `Code.gs` の中身を全部消して、このフォルダの `Code.gs` を貼り付けて保存
3. **自分の情報を書く**: ファイル上部の `CONFIG`（名前・署名・サービス内容・料金の目安）を書き換え
4. **APIキーを登録**: 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」→ プロパティ `ANTHROPIC_API_KEY`、値にキーを入れて保存
   （キーはコードに直接書かないでください）
5. **`setup` を実行**: 上の関数選択で `setup` を選んで「実行」→ Googleの権限確認を許可
   実行ログに次の3つのURLが出ます
   - フォーム（お客様に送るURL）→ SNSのプロフィールやWebページに載せる
   - フォームの編集URL
   - 記録シートのURL
6. **試す**: `testDraft` を実行 → 自分宛ての下書きがGmailにできれば成功。そのあと、実際にフォームから1件送ってみてください

## よくある調整
| やりたいこと | 変えるところ |
|---|---|
| 受付確認メールを送らない | `autoAck: false` |
| 通知を別のアドレスに | `notifyTo: 'xxx@gmail.com'` |
| 返信の文体・長さを変える | `draftWithClaude_` の中の「書き方」 |
| フォームの項目を増やす | フォームの編集URLから項目を追加（質問文を変えた場合は `Q` も合わせる） |

## 注意
- 無料のGmailアカウントは1日100通までの送信制限があります（受付確認＋通知で1件あたり2通）。
- `setup` を2回実行すると、フォームとシートがもう1組できます（トリガーは新しいフォームに付け替わります）。
