Claude の APIキーを作る

ブラウザで別のページを開きます ・ 5分

AIに返信文を書いてもらうための「合いことば」のようなものです。

  1. platform.claude.com を開き、ログイン（またはアカウント作成）
  2. 最初の画面の「組織のクレジット」が $0 なら、残高を追加 で5ドル分ほど購入します（すでに金額があれば不要）
  3. 同じ画面の API キーを取得 を押します（右上のメニュー → キー からでも同じ）
  4. 「コードはどこで実行されますか？」と聞かれたら、いちばん下の その他の場所 を選ぶ（上の3つは使いません）
  5. 名前に「お問い合わせ」と入れて作成
  6. sk-ant- で始まる長い文字が表示されるので、コピーしてメモアプリなどに一時保存（3からはパソコンで作業するので、パソコンでも見られる場所に）
注意　キーは一度しか表示されません。また、他人に見せたり、SNSやチャットに貼ったりしないでください。
料金は1件の返信につき数円ほどです。月に30件来ても100〜200円程度の見込みです。

「setup」を実行してフォームを作る
3分 ・ いちばん戸惑いやすいところです

    
    
      
  1. 画面上部、▶ 実行 ボタンの右にある選択欄で setup を選ぶ
    2. 
      
  2. ▶ 実行 を押す
    3. 
      
  3. 「承認が必要です」と出たら 権限を確認 → 自分のGoogleアカウントを選ぶ
    4. 
      
  4. 「このアプリは Google で確認されていません」と出たら、左下の 詳細 → （プロジェクト名）（安全ではないページ）に移動 を押す
    5. 
      
  5. アクセスの一覧が出たら すべて選択（ある場合）→ 続行 または 許可
    6. 
      
  6. 画面下に「実行ログ」が出て、「実行完了」と表示されれば成功です
    7. 
    

    
「確認されていません」の警告は、あなたが自分で作ったプログラムなので Google の審査を受けていない、という意味です。自分で書いたものなので許可して大丈夫です。

    
実行ログに3つのURLが出ます。いちばん大事なのは 「フォーム（お客様に送るURL）」です。これをコピーして、メモ帳に保存してください。

    
注意　setup は1回だけ実行してください。2回押すと、フォームがもう1つできてしまいます。
