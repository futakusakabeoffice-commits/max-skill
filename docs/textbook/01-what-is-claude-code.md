# 第1章 Claude Code とは

> **この章で学ぶこと**
> - Claude Code が、ふつうのチャット AI と何が違うのか
> - 仕事のどんな場面で役に立つのか
> - どこで使えて、何が必要なのか
> - 使う前に知っておきたい「AI との付き合い方」
>
> 所要時間の目安: 20分 ／ 前提: なし

---

## 1-1 Claude Code は「手を動かしてくれる AI」

Claude Code は、Anthropic 社の AI「Claude」が **あなたのパソコンのファイルを読み、編集し、コマンドを実行して、作業を最後までやり切ってくれる道具** です。

チャット AI に「請求書を集計する方法を教えて」と聞くと、**やり方** を教えてくれます。
Claude Code に「請求書を集計して」と頼むと、**実際にファイルを開いて集計し、結果をファイルに保存** してくれます。

| | チャット AI（claude.ai など） | Claude Code |
|---|---|---|
| ファイル | 自分でコピペして渡す | **自分でフォルダの中を探して読む** |
| 作業 | 答えやアドバイスをくれる | **実際にファイルを作る・書き換える・コマンドを実行する** |
| 確認 | 自分で試す | **自分で結果を確かめ、失敗したら直す** |
| 向いていること | 相談、文章の下書き | ホームページ作り、データ整理、資料作成、自動化など「手を動かす仕事」 |

> **コマンド** とは、パソコンに文字で出す命令のことです。Claude Code は必要なコマンドを自分で考えて実行します。あなたがコマンドを覚える必要は、ほとんどありません。

### Claude Code が働く仕組み

```text
あなた：「invoices フォルダの請求書を集計して」
   │
   ▼
Claude Code
   1. フォルダの中を見る      → 請求書ファイルが12個ある
   2. ファイルを読む          → 金額と取引先を取り出す
   3. 計算する                → 取引先ごとに合計する
   4. 結果をファイルに保存する → reports/集計.md
   5. 検算する                → 元データと合計が合っているか確認
   │
   ▼
あなた：「完了しました。合計は 482,000 円です」という報告を受け取る
```

この「見る → 考える → 動く → 確かめる」を、Claude Code は **自分で繰り返して** 作業を進めます。この働き方を **エージェント** と呼ぶこともあります。

---

## 1-2 「プログラマー向け」だけではない

Claude Code は「コードを書く AI」として紹介されることが多いのですが、実際には **フォルダの中のファイルを扱う仕事なら何でも** 任せられます。

さくらさんの場合、こんな使い方ができます。

| さくらさんの困りごと | Claude Code に頼むこと |
|---|---|
| 毎月の請求書の集計に2時間かかる | 「請求書 CSV を取引先ごとに集計して、表にして」 |
| お問い合わせへの返信を毎回ゼロから書いている | 「よくある質問5種類の返信テンプレートを作って」 |
| ブログ記事の「出来る/できる」がバラバラ | 「全記事の表記ゆれを探して一覧にして」 |
| 競合の講座の料金を調べるのが面倒 | 「競合5社の料金と特徴を比較表にして」 |
| 講座の申込ページを作りたい | 「講座の申込ページを作って。スマホでも見やすく」 |
| 毎朝の業界ニュースのチェックが大変 | 「毎朝、ニュースを5つ選んで要約して」（第14章） |

> **CSV** とは、表のデータを「,（カンマ）」で区切って保存したファイルです。Excel やスプレッドシートから書き出せます。

## 1-3 どこで使えるか

中身は同じ Claude Code で、使う場所（画面）を選べます。

| 使う場所 | 特徴 | こんな人に |
|---|---|---|
| **ターミナル（CLI）** | 基本の形。文字で指示する画面。機能がいちばん揃っている | 本書の中心。慣れると一番便利 |
| **デスクトップアプリ** | Mac / Windows 用のアプリ（Linux 版はベータ）。画面で操作できる | 黒い画面が苦手な人 |
| **Web（claude.ai/code）** | ブラウザから使う。クラウド上で動くので、パソコンを閉じても作業が続く | 外出が多い人 |
| **スマホ（Claude アプリ）** | 外出先から指示・確認ができる | 移動中に進めたい人 |
| **VS Code / JetBrains** | プログラミング用エディタの中で使う | エディタを使っている人 |
| **GitHub Actions など** | GitHub 上で `@claude` と書くと作業する | 第14章で紹介 |

> **ターミナル** は、文字でパソコンに命令する画面です。Mac では「ターミナル」、Windows では「PowerShell」というアプリがそれにあたります。CLI（コマンドラインインターフェース）とも呼ばれます。

本書は **ターミナルでの使い方** を中心に説明します。デスクトップアプリでも、ほとんどの内容はそのまま使えます。

> **注意**: Web やスマホから使う場合は、クラウド（Anthropic のサーバー）上で動きます。そのため、**自分のパソコンの中のファイルは直接は見えません**。手元のファイルを扱うなら、ターミナルかデスクトップアプリを使いましょう。

## 1-4 何が必要か

- **Claude の有料プラン**（Pro / Max / Ultra / Team / Enterprise）、または Claude Console（API）のアカウント
- **無料プランでは Claude Code は使えません**
- パソコン（Mac / Windows / Linux）

プランの選び方は [第2章](02-setup.md) で説明します。

## 1-5 AI と上手に付き合うための心構え

Claude Code はとても頼りになりますが、**魔法ではありません**。使い始める前に、次の4つを覚えておいてください。

### ① 自信満々に間違えることがある

AI は、間違った内容でも自然な文章で言い切ることがあります。特に次のものは、**最後に必ず自分で確かめましょう**。

- 数字の集計結果（売上、請求金額など）
- 法律・税金・契約に関わること
- Web で調べた情報（古い・不正確なことがある）

「検算して」「出典の URL を付けて」と頼むと、間違いに気づきやすくなります（[第4章](04-prompting.md)）。

### ② 最後に決めるのは人

本書のルールは **「Claude は下書きまで、送信・公開・支払いは人がする」** です。削除など取り返しのつかない操作も、**内容を見てから実行させる** のが基本です。Claude Code は危なそうな操作の前に確認を求めてきます（[第5章](05-permissions-settings.md)）。

### ③ 読ませたものに「隠れた指示」が入っていることがある

Web ページやファイルの中に「この情報を送信せよ」のような指示が紛れ込んでいると、Claude がそれに引っ張られることがあります。これを **プロンプトインジェクション** といいます。詳しくは [第7章](07-safety.md) で説明します。

### ④ 分からないことは Claude Code 自身に聞けばいい

使い方で迷ったら、Claude Code にそのまま聞いてください。

```text
Claude Code で、前回の会話の続きから始める方法を公式ドキュメントで調べて教えて
```

```text
今実行したコマンドは何をしたの？ 初心者向けに説明して
```

作業しながら「説明しながら進めて」と頼めば、**仕事をしながら学べます**。

## 1-6 Claude Code は更新が速い

Claude Code には、月単位で新しい機能が追加されます。コマンドの名前や画面が変わることもあります。

- 本書の内容と画面が違うときは、**バージョンにより異なる** 可能性があります
- 困ったら [公式ドキュメント](https://code.claude.com/docs/) を確認するか、Claude Code に聞く
- 新しい機能を追いかけすぎず、**自分の仕事に必要なものだけ** 覚えれば十分です

## やってみよう

### 練習1：任せたい仕事リストを作る

- **目的**: 自分の仕事のどこに Claude Code を使えるかを見つける
- **手順**:
  1. 紙かメモアプリに、この1週間でやった「パソコン作業」を10個書き出す
  2. それぞれに「毎週やる」「時間がかかる」「手順が決まっている」の当てはまる数を書く
  3. 数が多いものを3つ選ぶ
- **期待する結果**: Claude Code に最初に任せる仕事の候補が3つ決まる
- **うまくいかないとき**: 1-2 の表を見て、「似ている作業」がないか探してみましょう

### 練習2：使う場所を決める

- **目的**: 自分に合った使い方を選ぶ
- **手順**: 1-3 の表を見て、「主に使う場所」と「サブで使う場所」を1つずつ決める
- **期待する結果**: 例「主にターミナル、外出時はスマホ」
- **うまくいかないとき**: 迷ったら、本書と同じ **ターミナル** から始めましょう

## まとめ

- Claude Code は、ファイルを読み・作り・直し・確かめるところまで **自分でやってくれる AI の道具**
- プログラミング以外にも、集計・文章・資料・調査など **ファイルを扱う仕事** に幅広く使える
- ターミナル、デスクトップアプリ、Web、スマホなどで使える。Web とスマホは **クラウドで動く**
- 使うには **有料プラン** が必要
- AI は間違えることがある。**最後の確認と判断は人がする**
- 分からないことは **Claude Code 自身に聞く**
