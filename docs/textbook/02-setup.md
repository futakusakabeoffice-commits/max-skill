> **この章で学ぶこと**
> - 自分に合ったプランの選び方

>
> 所要時間の目安: 30分 ／ 前提: [第1章](01-what-is-claude-code.md)

## 2-1 プランを選ぶ

Claude Code を使うには、次のどれかが必要です。

| 選択肢 | 特徴 | 向いている人 |
|---|---|---|
| **Pro** | 個人向けの有料プラン。利用量に上限あり | まず試したい人、使うのは1日1〜2時間程度の人 |
| **Max / Ultra** | Pro より利用量の上限が大きい個人向けプラン | 毎日しっかり使う人、上限によく当たる人 |
| **Team / Enterprise** | 会社・チーム向け。管理機能がある | 複数人で使う組織 |
| **Claude Console（API）** | 使った分だけ料金がかかる従量課金 | 開発者、利用量を細かく管理したい人 |

- **無料プランでは使えません**
- 料金や上限の細かい条件は変わることがあるので、申し込む前に公式サイトで確認してください
- **迷ったら Pro から始めて**、毎日のように上限に当たるようになったら上位プランを検討するのがおすすめです（[第9章](09-context-cost.md)）

> **注意**: サブスクリプション（Pro / Max など）は「定額で一定量まで」、API は「使った分だけ課金」です。API で長時間作業させると、思ったより料金がかかることがあります。初心者はサブスクリプションが安心です。

## 2-2 ターミナルを開く

Claude Code は **ターミナル** で動かすのが基本です。

| パソコン | 開き方 |
|---|---|
| **Mac** | `⌘ + Space` で Spotlight を開き、「ターミナル」と入力して Enter |
| **Windows** | スタートメニューで「PowerShell」と入力して開く |

黒（または白）い画面に、文字を入力できる場所が出てきます。

### 最低限覚える3つのコマンド

| コマンド | 意味 | 例 |
|---|---|---|
| `cd フォルダ名` | そのフォルダに移動する（change directory） | `cd my-project` |
| `mkdir フォルダ名` | フォルダを作る（make directory） | `mkdir my-project` |
| `ls` | 今いるフォルダの中身を表示する（Windows の PowerShell でも使える） | `ls` |

> **注意**: コマンドは1文字でも違うと動きません。本書のコマンドは **コピーして貼り付ける** のが確実です。ターミナルへの貼り付けは、Mac は `⌘ + V`、Windows の PowerShell は右クリックか `Ctrl + V` です。

## 2-3 インストールする

使っているパソコンに合わせて、ターミナルで **1行だけ** 実行します。

### Mac / Linux

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

> Windows で WSL（Windows の中で Linux を動かす仕組み）を使っている人もこちらです。分からなければ、下の PowerShell の方を使ってください。

### Windows（PowerShell）

```powershell
irm https://claude.ai/install.ps1 | iex
```

> Windows で Git for Windows（Git という道具の Windows 版）のインストールが求められた場合は、[第6章 6-2](06-git.md) を参照してください。

### ほかの入れ方

| 方法 | コマンド | 注意 |
|---|---|---|
| Homebrew（Mac 用のソフト管理ツール） | `brew install --cask claude-code` | 自動更新されない。ときどき `brew upgrade claude-code` を実行する。最新版の `claude-code@latest` を入れた場合は `brew upgrade claude-code@latest` |
| WinGet（Windows 用のソフト管理ツール） | `winget install Anthropic.ClaudeCode` | 自動更新されない。ときどき `winget upgrade Anthropic.ClaudeCode` を実行する |

Homebrew や WinGet を使ったことがなければ、気にしなくて大丈夫です。特にこだわりがなければ、上の **1行のインストール** がおすすめです（自動で最新版に更新されます）。

### 入ったか確認する

```bash
claude --version
```

バージョン番号（例: `2.x.x`）が表示されれば成功です。

> `claude: command not found`（コマンドが見つからない）と出たら、**ターミナルを一度閉じて開き直して** から、もう一度試してください。それでも出る場合は [付録C](appendix-c-troubleshooting.md) を見てください。

## 2-4 作業用フォルダを作る

Claude Code は、**起動したフォルダの中** を作業場所にします。仕事ごとに専用のフォルダを作りましょう。

本書では、ホームフォルダ（自分のユーザー用のフォルダ。`~` と書きます）の中に `sakura-work` というフォルダを作り、第2〜14章の練習で共通して使います。

```bash
cd ~                # ホームフォルダに移動する
mkdir sakura-work   # フォルダを作る
cd sakura-work      # そのフォルダに移動する
```

次回からは `cd ~/sakura-work` でこのフォルダに移動できます。ファイルの画面で開きたいときは、次のように入力します。

| パソコン | フォルダを開くコマンド |
|---|---|
| Mac | `open .` |
| Windows | `explorer .` |

（`.` は「今いるフォルダ」という意味です）

> **注意**: **デスクトップやホームフォルダそのものでは `claude` を起動しないでください**。Claude はそのフォルダの中身全部を作業対象として扱えてしまうので、関係のないファイルや個人的なファイルまで読んだり変更したりできる状態になります。**作業ごとに専用のフォルダを作る** のが基本です。

---

## 2-5 起動してログインする

作業用フォルダの中で、次を入力します。

```bash
claude
```

初めての起動では、次のような流れになります。

1. 画面の見た目（テーマ）などを選ぶ
2. ログイン方法を選ぶ → Pro / Max などのプランを使うなら **Claude のサブスクリプション（Claude account）** の方を選ぶ
3. **ブラウザが開き、ログインを求められる** → Claude のアカウントでログインする。ブラウザにコードが表示された場合は、それをコピーしてターミナルに貼り付ける
4. このフォルダを信頼するか（trust）を英語で聞かれる → 自分で作ったフォルダなら「Yes」を選ぶ
5. 入力欄が表示されたら準備完了

> 画面は英語で表示されます。流れや文言はバージョンにより異なることがあるので、表示された説明をよく読んで進めてください。

### アカウントを切り替えたいとき

Claude Code の中で次を入力します。

```text
/login
```

`/` から始まる命令を **スラッシュコマンド** といいます。Claude Code の中で使う、特別な命令です。

## 2-6 更新と診断

### 最新版にする

1行のインストールで入れた場合は、**自動で更新** されます。手動で更新したいときは次のとおりです。

```bash
claude update
```

### 調子がおかしいときの診断

| 場所 | コマンド | 何をするか |
|---|---|---|
| ターミナル | `claude doctor` | インストールや設定の状態を診断する |
| Claude Code の中 | `/doctor` | 不調を診断し、直し方を提案する |

## 2-7 ファイルの保存のしかた・開き方

本書では、ときどき「このファイルを保存してください」という場面が出てきます。

> **ファイルの保存のしかた**
> - **一番簡単なのは、Claude に頼むこと** です。「この内容で `.claude/agents/proofreader.md` を作って」と内容ごと貼り付ければ、正しい場所に作ってくれます
> - 自分で作るなら、**VS Code** などのテキストエディタ（文字だけを編集するアプリ）がおすすめです
> - Mac の「テキストエディット」を使う場合は、**「フォーマット」→「標準テキストにする」** を選んでから保存します。また、引用符（`"`）が自動で “ ” に変わる機能（スマート引用符）がオンだと、JSON などの設定が壊れるので注意
> - Windows の「メモ帳」は、保存時に名前の最後に `.txt` が勝手に付くことがあります。ファイル名を確認しましょう
> - `.claude` のように `.` で始まるフォルダは、Finder やエクスプローラーでは作りにくいので、ターミナルで `mkdir -p .claude/agents` のように作るか、Claude に頼みます

### 隠しファイルを表示する

`.` で始まるファイルやフォルダは **隠しファイル** として、普段は表示されません。

| パソコン | 表示する方法 |
|---|---|
| Mac（Finder） | `⌘ + Shift + .` |
| Windows 11（エクスプローラー） | 「表示」→「表示」→「隠しファイル」にチェック |

### `.md` ファイルを開く

本書でよく出てくる `.md`（Markdown）ファイルは、文字だけのファイルです。

- Claude Code に「@reports/集計.md の中身を表示して」と頼む
- テキストエディタ（VS Code、メモ帳など）で開く

## 2-8 画面操作が好みなら：デスクトップアプリ

黒い画面がどうしても苦手な人は、**デスクトップアプリ** から始めることもできます。Claude の公式サイトからダウンロードできます。

- 本書の内容は、ほとんどそのまま当てはまります
- ただし、一部の操作やキー操作は画面によって違います
- Web 版（claude.ai/code）はクラウドで動くため、手元のファイルを扱う第3章の手順とは異なります

## やってみよう

### 練習1：インストールして確認する

- **目的**: Claude Code を使える状態にする
- **手順**:
  1. ターミナルを開く（2-2）
  2. 自分のパソコン用のインストールコマンドを実行する（2-3）
  3. `claude --version` を実行する
- **期待する結果**: バージョン番号が表示される
- **うまくいかないとき**: ターミナルを開き直して再度 `claude --version`。それでもだめなら [付録C](appendix-c-troubleshooting.md)

### 練習2：作業用フォルダで起動する

- **目的**: 正しい場所で Claude Code を起動する
- **手順**:
  1. `cd ~` → `mkdir sakura-work` → `cd sakura-work`
  2. `open .`（Windows は `explorer .`）でフォルダが開くか確かめる
  3. `claude` で起動し、ログインする
- **期待する結果**: 入力欄が表示される
- **うまくいかないとき**: ログインできない場合は、有料プランに入っているか確認しましょう

### 練習3：Claude Code に自己紹介してもらう

- **目的**: 会話できることを確かめる
- **手順**: 入力欄に「あなたは何ができますか？ 初心者向けに3つ教えて」と入力して Enter
- **期待する結果**: 日本語で答えが返ってくる
- **うまくいかないとき**: 何も起きない場合は、`/doctor` を実行してみましょう

## まとめ

- **有料プランが必要**。迷ったら Pro から始め、上限によく当たるなら上位プランへ
- ターミナルは Mac なら「ターミナル」、Windows なら「PowerShell」
- インストールは **1行のコマンド**。`claude --version` で確認
- **作業ごとに専用フォルダを作り、その中で `claude` を起動する**。デスクトップやホームフォルダでは起動しない
- 調子が悪いときは `claude doctor`（ターミナル）か `/doctor`（Claude Code の中）

**問1** Mac で Homebrew を使ってインストールした場合、気をつけることは何でしょう？

<details><summary>答えを見る</summary>

**自動更新されない** ことです。ときどき `brew upgrade claude-code` を実行して、最新版にする必要があります。

**問2** さくらさんがデスクトップで `claude` を起動しようとしています。何と声をかけるべきでしょう？

<details><summary>答えを見る</summary>

「**作業用のフォルダを作って、その中で起動しよう**」です。デスクトップで起動すると、デスクトップにある関係ないファイルまで Claude が扱える状態になってしまいます。
</details>

**問3** ターミナルで `claude doctor` と、Claude Code の中で `/doctor` の違いは何でしょう？

<details><summary>答えを見る</summary>

`claude doctor` は **ターミナルから** インストールや設定の状態を診断するコマンドです。`/doctor` は **Claude Code の中で** 使い、不調を診断して直し方を提案してくれます。
</details>

**問4** `cd sakura-work` は何をするコマンドでしょう？

<details><summary>答えを見る</summary>

`sakura-work` というフォルダに **移動する** コマンドです（cd = change directory）。
</details>
