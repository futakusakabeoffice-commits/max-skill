# 第3章 はじめての作業

> **この章で学ぶこと**
> - Claude Code に作業を頼み、確認画面に正しく答える方法
> - 会話しながら少しずつ直していく進め方
> - ファイルの指定（`@`）と画像の見せ方
> - 作業を止める・巻き戻す・続きから始める方法
>
> 所要時間の目安: 40分 ／ 前提: [第2章](02-setup.md)（インストールとログインが済んでいること）

---

## 3-1 最初のお願いをする

さくらさんは、オンライン講座の **紹介ページ** を作ることにしました。

作業用フォルダ（第2章で作った `~/sakura-work`）の中で `claude` を起動し、入力欄にふつうの日本語で書きます。

> **複数行の入力のしかた**: 依頼文が長いときは、どこかで書いた文章を **貼り付ける** のが簡単です（改行もそのまま入ります）。自分で改行したいときは、行の最後に `\` を入力してから Enter を押します（どの環境でも使えます）。多くのターミナルでは `Shift + Enter` でも改行でき、うまくいかないときは `/terminal-setup` で設定できます。

```text
オンライン講座「はじめての Web デザイン」の紹介ページを index.html に作って。
講師は「さくら」、全6回、受講料は29,800円。申込ボタンも付けて。スマホでも見やすくして。
```

Enter を押すと、Claude は次のように動きます。

1. 何を作るか考える（考えている内容が画面に表示されることもあります）
2. ファイルを作ってよいか **確認を求めてくる**
3. `index.html` を作って、何をしたかを報告する

> **HTML** は、ホームページを作るための書き方です。ファイル名が `.html` で終わるファイルは、ブラウザで開くとページとして表示されます。

## 3-2 確認画面の読み方

Claude Code は、ファイルを作る・変える、コマンドを実行するなどの前に、**「やってもいいですか？」と確認** してきます。画面は英語で、たとえば次のように表示されます。

```text
Do you want to create index.html?
❯ 1. Yes
  2. Yes, and don't ask again …
  3. No, and tell Claude what to do differently
```

（表示される文言はバージョンにより異なります）

| 選択肢 | 意味 | 使いどき |
|---|---|---|
| **Yes** | 今回だけ許可する | 迷ったらこれ |
| **Yes, and don't ask again** | 同じ種類の操作を次から自動で許可する | 何度も出てきて、安全だと分かっている操作 |
| **No** | 許可しない。代わりの指示を出せる | 何をしようとしているか分からないとき |

> **確認画面が出てこないときは**: 最近のバージョン（v2.1.283 以降）では、確認を AI が自動で判断する **auto モード** で始まることがあり、その場合は確認画面がほとんど出ません。画面の下の表示（例: `auto mode on`、`⏸ plan mode on`、`accept edits on` など。表示はバージョンにより異なる）で今のモードを確かめ、練習のあいだは `Shift + Tab` を何回か押して、通常モード（「Manual」と表示されることがあります）に切り替えておきましょう。モードについては [第5章](05-permissions-settings.md) で詳しく学びます。

> **注意**: 確認画面は **読んでから** 選びましょう。何をしようとしているか分からないときは、**No を選んで「今何をしようとしてる？ 初心者向けに説明して」と聞けば OK** です。急いで Yes を押し続けるのが一番の事故のもとです。

どこまで確認なしで任せるかは、[第5章](05-permissions-settings.md) で詳しく学びます。

## 3-3 できたものを見て、直してもらう

作業が終わったら、作業用フォルダを開いて（Mac は `open .`、Windows は `explorer .`）、`index.html` をダブルクリックします。ブラウザでページが表示されます。

気になるところがあれば、そのまま頼みます。

```text
全体の色を淡いピンク系にして、受講料の文字をもっと目立たせて
```

```text
「受講生の声」のコーナーを、申込ボタンの上に追加して。声は3人分、仮の内容でいいよ
```

このように **会話しながら少しずつ直していく** のが基本の使い方です。一度で完璧を目指すより、何度かやり取りする方が早く、イメージに近づきます。

> Claude は、そのままでは **ブラウザの画面を自分で見ることはできません**。見た目の確認は自分でブラウザで開いて行い、Claude には「表示に関わる部分を見直して、問題がないか報告して」と頼みます。Claude にページを実際に見させるには、ブラウザ操作の MCP（[第13章](13-mcp-plugins.md)）が必要です。確認の頼み方は [第4章](04-prompting.md) で学びます。

## 3-4 ファイルを指定する（`@`）

入力欄で `@` を入力すると、フォルダの中のファイル名の候補が出ます。ファイルを指定すると、Claude はその中身を読んでから作業します。

```text
@index.html の文章を、もっと親しみやすい言葉づかいに直して
```

```text
@memo/講座の特徴.txt の内容を使って、紹介ページの「この講座の特徴」を書き直して
```

ファイル名を正確に指定すると、Claude が探し回る手間が省け、**早く・正確に** なります。

---

## 3-5 画像を見せる

スクリーンショットやデザインの画像も見せられます。

| やり方 | 操作 |
|---|---|
| ドラッグ＆ドロップ | 画像ファイルを入力欄に引っ張ってくる |
| 貼り付け | コピーした画像を `Ctrl + V`（**Mac でも基本は ⌘ ではなく Ctrl**。iTerm2 では `⌘ + V` も可。Windows は `Alt + V`） |
| ファイルの場所を書く | 「`images/参考デザイン.png` を見て」と書く |

```text
（画像を貼り付けて）このページのような、余白の多い落ち着いたデザインにして
```

## 3-6 止める・巻き戻す

### 作業を止める

Claude が思っていない方向に進み始めたら、すぐに **`Esc`** を押します。作業が止まるので、指示を言い直しましょう。

```text
ごめん、ページ全体は変えないで。申込ボタンの色だけ変えて
```

### 前の状態に巻き戻す

「さっきの方がよかった」というときは、**入力欄が空の状態で `Esc` を2回** 押すか、次のコマンドを使います。

```text
/rewind
```

戻りたい時点を選ぶと、次のような選び方ができます。

| 選択肢 | 意味 |
|---|---|
| ファイル（コード）も会話も戻す | その時点に丸ごと戻る |
| 会話だけ戻す | ファイルはそのまま、会話だけやり直す |
| ファイルだけ戻す | 会話はそのまま、ファイルだけ元に戻す |

> **注意**: 巻き戻しで戻せないものもあります。**Claude がコマンドだけで変えたファイル（編集ツールで触っていないもの）** や、サブエージェント（[第11章](11-subagents.md)）による変更の多くは戻りません。大事な作業は **Git でセーブポイントを作っておく** と安心です（[第6章](06-git.md)）。

### 会話をリセットする

まったく別の作業に移るときは、会話をリセットします。

```text
/clear
```

前の作業の話が残っていないので、Claude が混乱しにくくなります。会話の区切り方は [第9章](09-context-cost.md) で詳しく学びます。

---

## 3-7 自分でコマンドを実行する（`!`）

入力の先頭に `!` を付けると、それを **ターミナルのコマンドとしてそのまま実行** し、結果を会話に入れられます。

```text
! ls
```

（フォルダの中身の一覧が表示され、Claude もその結果を見られます）

普段は Claude に頼めば十分なので、無理に使う必要はありません。

---

## 3-8 終了と、続きから始める方法

### 終了する

```text
/exit
```

または、入力欄が空の状態で `Ctrl + C` を2回押します（**Mac でも ⌘ ではなく Ctrl**）。

### 次回、続きから始める

同じフォルダで、次のように起動します。

| やりたいこと | 方法 |
|---|---|
| 前回の会話の続きから始める | `claude -c` |
| 過去の会話を一覧から選んで再開する | `claude --resume`（Claude Code の中なら `/resume`） |
| 今の会話に名前を付けておく | Claude Code の中で `/rename` |

会話に「講座ページ作り」のような名前を付けておくと、あとで探しやすくなります。

### 覚えておくと便利な操作

| 操作 | 何をするか |
|---|---|
| `/help` | ヘルプ（使えるコマンドの一覧など）を表示する |
| `↑` / `↓` | 前に入力した依頼文を呼び出す |
| `Ctrl + R` | 過去の入力を検索する |
| `Ctrl + D` を2回 | 終了する（`Ctrl + C` 2回と同じ） |
| `claude "〜して"` | 最初の依頼付きで起動する（例: `claude "index.html の誤字を探して"`） |

## やってみよう

### 練習1：講座の紹介ページを作る

- **目的**: 依頼 → 確認 → 完成の流れを体験する
- **手順**:
  1. `sakura-work` フォルダで `claude` を起動
  2. 3-1 の依頼文を、自分の仕事の内容に書き換えて入力
  3. 確認画面を読んで Yes を選ぶ
  4. できた `index.html` をブラウザで開く
- **期待する結果**: 自分の仕事を紹介するページが表示される
- **うまくいかないとき**: ファイルが見つからないときは「index.html はどこに作った？」と聞きましょう

### 練習2：3回直して、1回巻き戻す

- **目的**: 会話で直す・巻き戻すに慣れる
- **手順**:
  1. 色、文章、レイアウトについて、1つずつ3回直してもらう
  2. `/rewind` を開くと、これまでに自分が送った依頼の一覧が出るので、**2回目に頼んだ依頼** を選び、「ファイル（コード）も会話も戻す」を選ぶ
  3. ブラウザでページを再読み込みして確かめる
- **期待する結果**: 2回目の直しの前の見た目に戻っている
- **うまくいかないとき**: 戻らない場合は、「さっきの〇〇の変更を元に戻して」と言葉で頼んでもかまいません

### 練習3：終了して続きから始める

- **目的**: 作業を中断・再開できるようにする
- **手順**: `/rename` で会話に「講座ページ」と名前を付ける → `/exit` で終了 → `claude -c` で再開 → 「ここまで何をしたか3行でまとめて」と聞く
- **期待する結果**: 前回の作業内容のまとめが返ってくる
- **うまくいかないとき**: 別のフォルダで起動していないか確認しましょう（`claude -c` は同じフォルダでの続きです）

## まとめ

- 頼むときは **ふつうの日本語** でよい。作業の前に確認画面が出る
- 確認画面は **読んでから** 選ぶ。分からなければ No を選んで質問する
- **会話しながら少しずつ直す** のが基本
- `@` でファイルを指定、画像は貼り付けやドラッグ＆ドロップで見せる
- 止めるのは `Esc`、巻き戻しは `Esc` 2回か `/rewind`、別の作業に移るときは `/clear`
- 続きからは `claude -c`、過去の会話は `claude --resume`
