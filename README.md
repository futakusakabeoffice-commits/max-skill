# 起業司令室

AIで起業を目指すための、毎日の「指令」と朝刊をまとめた個人用アプリです。

- 公開ページ（非公開・本人のみ）: https://claude.ai/artifact/XfJowpDGAcCsYKYse1SfvS
- ソース: `app/index.html`
- 朝刊を作る定期タスクの指示文: `app/morning-brief-prompt.md`（毎朝 7:37 JST に実行し、スマホに通知）

## 機能
| 画面 | 内容 |
|---|---|
| 今日 | 本日の指令（チェックで「済」の判子）、予定と空き時間に合わせた作業量、AIで組み直し、一言日記 |
| 朝刊 | X・Instagram・TikTok・YouTube・生成AI・ニュースのトレンドと「ビジネスの種」、投稿案 |
| 調べる | 競合・相場、AIツール、SNS集客などを調べる。AIがすぐ要点を答え、Webでの出典付き調査も予約できる |
| 文章 | SNS投稿（X・Instagram・TikTok台本・YouTube台本）、ブログ・note記事、販売・営業文（ココナラ出品文・LP・営業DM・応募文）をAIが下書き。「短く」「やわらかく」「数字で説得」などの推敲ボタン、一部だけの書き直し、指示しての書き直し、元に戻す、文字数（Xは全角換算140字）、タイトル案・添削、保存と発信の下書きへの送信。収入の記録と日記を実績として使い、ない実績は作らない |
| 予定 | 独自カレンダー。バイトや予定を入れると、その日のタスクが自動で組み直される |
| 記録 | アイデア帳・一言日記・SNS発信の下書き（AIで投稿案作成） |
| 収入 | 月の合計とAI・バイト・その他の内訳、何で稼いだか（金額順）、6か月の推移、日別明細、実質時給の比較。バイト代はシフトから自動計算（深夜22〜5時と1日8時間超は25%増、休憩は6時間超45分・8時間超60分を自動、交通費込み） |
| 成長 | 連続達成日、14日間の達成率、週の振り返りとAIコーチの講評、90日ロードマップ、学習カリキュラム45回、設定 |

## タスクの決まり方
1. 予定（バイトは前後の移動時間込み）から、その日の自由時間を計算
2. 作業の目安 = 自由な日は最大5時間、バイトの日は自由時間の35%（最大3時間、最低45分）
3. 毎日必ず：朝刊とアイデア1つ／学習1回／SNS投稿1本／一言日記（日曜は週の振り返り）
4. 残りの時間に、90日ロードマップの実践タスクを順番に入れる（終わらなかった分は翌日へ繰り越し）

## データ
claude.ai のアーティファクトのデータベースに保存（collections: `config`, `days`, `events`, `briefs`, `ideas`, `diary`, `posts`, `reviews`, `income`, `research`, `writings`）。
